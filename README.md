# Arduino_Experiments

This repository contains five practical Arduino experiments completed using the Wokwi Simulator.

Exercise 1: SOS Beacon

An LED blinks in an SOS pattern using short and long flashes to represent Morse code.

https://wokwi.com/projects/479517962576931841

Exercise 2: Two LEDs Alternating

Two LEDs turn ON and OFF alternately, switching every 300 milliseconds.

https://wokwi.com/projects/479677499840350209

Exercise 3: Button Controls LED Blinking Speed

A push button controls the LED blinking speed. The LED blinks faster when the button is pressed and slower when released.

https://wokwi.com/projects/479680637501684737

Exercise 4: Button Press Counter

A push button counts the number of presses and displays the count on the Serial Monitor.

https://wokwi.com/projects/479683875526565889

Exercise 5: Toggle LED

Each button press changes the LED state from ON to OFF or from OFF to ON. The LED maintains its state until the next press.

https://wokwi.com/projects/479686243466941441
