# Arduino_Experiments

Arduino Experiments

This repository contains five Arduino experiments completed using the Wokwi Simulator as part of the Robotics Foundation course.

Experiments

1. SOS Beacon
2. Two LEDs Alternating
3. Button Controls LED Blinking Speed
4. Button Press Counter
5. Toggle LED

The experiments demonstrate practical applications of Arduino programming, including LED control, push buttons, and basic circuit operations.
